# 자동차 경주 게임
## 구현 기능 목록

### 📍입력 기능
#### 1. 자동차 이름 입력
- [x] 첫줄에 경주할 자동차 이름 입력.
- [x] 자동차 이름은 쉼표(,)를 기준으로 구분.
#### 2. 시도 횟수 입력
- [x] 시도 횟수 입력.

### 📍자동차 경주 기능
#### 1. 자동차 전진/정지 판단
- [x] 0에서 9 사이 무작위 값을 구함.
- [x] 무작위 값이 4 이상일 경우 전진, 아닐 경우 정지.
#### 2. 우승자 선정
- [x] 전진 횟수가 가장 많은 자동차들을 우승자로 선정.

### 📍출력 기능
#### 1. 자동차 이름 입력 메시지 출력
- [X] 자동차 이름 입력 메시지 출력
#### 2. 시도 횟수 입력 메시지 출력
- [X] 시도 횟수 입력 메시지 출력
#### 3. 차수별 실행 결과 출력
- [ ] 실행 결과 출력 메시지 출력.
- [ ] 차수별 실행 결과 출력.
#### 4. 우승자 출력
- [ ] 우승자 출력 메시지 출력.
- [ ] 우승자를 출력. 여러 명일 경우 쉼표(,)로 구분하여 출력.

### 예외 처리
#### 1. 자동차 이름 입력
- [x] 이름의 길이가 5자 초과인 경우
- [x] 이름이 null이나 공백인 경우
- [x] 중복된 자동차 이름을 입력한 경우
#### 2. 시도 횟수 입력
- [x] 시도 횟수가 null이나 공백인 경우
- [x] 시도 횟수가 정수가 아닌 경우
- [x] 시도 횟수가 양의 정수가 아닌 경우
